# thefollower

THE FOLLOWER — 심령 라이브 방송 콘셉트의 크래시 게임 POC (모바일 웹, 1080×1920).

## 실행

오디오를 fetch로 디코딩하므로 `file://`이 아닌 http로 열어야 합니다.

```bash
python -m http.server 8771
```

브라우저에서 `http://localhost:8771/poc/index.html`을 엽니다. 우측 상단 ☰ 버튼은 치트 메뉴입니다. 크래시 배수(덮치는 지점)와 除霊 보너스 금액(베팅의 0~20배)을 다음 라운드 1회 또는 매 라운드 고정으로 지정할 수 있습니다. 보너스 금액을 지정하면 小判이 모자랄 때 필요한 만큼 채워 주고, 슬롯에서 자연히 나올 수 없는 값은 가장 가까운 결과를 재생한 뒤 마지막 합계만 지정값으로 맞춥니다. 치트가 켜져 있으면 ☰ 버튼에 빨간 점이 표시됩니다.

## 구성

- `poc/` — 게임 (`index.html`, `style.css`, `content.js`, `slot.js`, `game.js`)
- `assets/` — 런타임 에셋과 원본 (`src/` 생성 이미지, `kling/` 괴물 원본 영상, `fonts/src/` 원본 폰트)
- `tools/` — 에셋 파이프라인과 검증 스크립트
- `시안/` — 콘셉트 시안 이미지 (`시안/slot/` 除霊 보너스 시안)

## 除霊 보너스 (미니게임)

촬영 중 배수가 1.5 · 2 · 3 · 5 · 10 · 20 · 50 · 100x를 넘을 때마다 채팅이 小判을 던집니다.
도망(캐시아웃)에 성공하면 결과 카드가 슬롯으로 커지고, 小判 한 개당 한 번씩 자동으로 돌아갑니다(5릴 × 3행, 243 ways, 小判 와일드).
당첨은 귀신에게 데미지를 주고 소액을 주며, HP를 다 깎으면 除霊 보상(베팅의 0.5 / 1 / 2 / 5배)이 붙습니다.
보너스는 배수가 아니라 추가 금액입니다: 최종 지급 = 도망 지급액 + 베팅 × 보너스(최대 베팅의 20배).

크래시가 메인이라 보너스 기댓값은 작게(小判 하나당 베팅의 약 3%, 8개여도 33%) 잡고, 대신 매 스핀 이벤트가 자주 터지게 했습니다.
캐시아웃 배수와 상관없는 고정 금액이라, 크래시 곡선이 깎이는 폭도 높은 배수로 갈수록 0에 가까워집니다
(일반 크래시 대비 2x −2.9%, 10x −1.8%, 100x −0.3%).

- 祟り: 귀신이 릴 하나를 봉인해 그 스핀에는 鬼火만 나옴 (첫 스핀 제외, 11%)
- 応援: 시청자 투척 스핀, 데미지와 배당 ×2 (9%)
- 小判拡大: 2~4번 릴에 小判이 서면 30% 확률로 릴 전체가 와일드
- 連撃: 연속 당첨 콤보, 데미지 ×1.5 / ×2 / ×2.5 / ×3

小判 4개면 80%, 8개면 97% 확률로 이 중 하나 이상이 터집니다. 이벤트는 주로 데미지(=除霊 확률)를 움직이고 지급은 조금만 움직입니다.

小判 사이 구간에서 캐시아웃하면 채팅이 도망가는 순간 다음 小判을 "마지막 投げ銭"으로 던져 줄 때가 있습니다.
확률은 다음 小判까지 얼마나 왔는지에 비례하고(1.49x면 거의 확실, 1.01x면 거의 없음), 화면에는 숫자 없이 채팅 연출로만 보입니다.

수학은 `poc/slot.js` 한 곳에 있습니다. 크래시 곡선은 P(배수 ≥ m) = 0.97 / (m + `prizeAt(m)`)이고, `prizeAt`은
보너스 기댓값 `PRIZE[K]`에 마지막 小判 확률(`kobanChance`)까지 더한 값이라 어디서 캐시아웃하든 RTP는 정확히 97%입니다. 지급 여부는 캐시아웃
순간에 정해지므로 타이밍으로 노릴 수 있는 틈은 없습니다.

```bash
node tools/slot_sim.mjs           # 스핀/보너스 통계
node tools/slot_sim.mjs --write   # 측정한 PRIZE 표를 slot.js에 기록 (릴 가중치나 배당을 바꾼 뒤)
node tools/slot_sim.mjs --rtp     # 크래시 + 보너스 전체 라운드 RTP 검증
```

## 배포용 zip

```bash
python tools/build_release.py
```

`release/TheFollower_POC.zip`이 만들어지며, zip 루트에 `index.html`이 있어 정적 호스팅에 그대로 올릴 수 있습니다.
Flux는 업로드당 파일을 1000개까지만 보존하므로, 몬스터 프레임은 클립마다 `.bin` 파일 하나로 묶여 들어갑니다.
